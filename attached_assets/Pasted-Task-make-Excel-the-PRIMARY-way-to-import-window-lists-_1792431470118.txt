STEP 2: EXCEL PARSER (primary) for the confirmation / window list
Sample file format (Confirmation_sample_excel.xlsx):
- Sheet name = client name. Handle multiple sheets (let the user pick or import each).
- Header block (label in column A or D, value to the right, values often in merged cells such as E10:K10, so read the top-left cell of the merge): ORDER NO, DATE, Client Name, Contact Details, Address, GSTIN, Final Measurement Taken by / Check by, Reference, CONFIRMATION MADE BY, DECISION GIVEN BY, CHECKED BY, FINAL MEASUREMENT DATE, INSTALLATION DATE.
- Window table: find the header row by SEARCHING for the labels, do not hardcode row 19. Expected columns: SR NO, Location, Width, Height, Total Sq Feet, Qty, Window Type, Glass, Lock Type, Profile, Mesh, then an optional separate block FINAL MEASUREMENT and its Total Sq Feet (columns M/N, with an empty spacer column L between them). Map columns by header text (case-insensitive, trim, ignore extra spaces/trailing spaces, tolerate small spelling variants like "Measurment"), never by position.
- Data rows start under the header and end at the row whose label is TOTAL (or the first fully empty run). Import EVERY row between them including rows with a blank SR NO or merged cells. Never skip a row silently; if a row is skipped or incomplete, add it to warnings with the row number.
- Values: Width and Height are in millimetres. Total Sq Feet is a formula (Width x Height / 92903). Read cached values, and if the cache is empty recompute it from width, height and qty. Compare the computed value with the sheet value and warn on mismatch above 0.5 percent. Qty defaults to 1 if blank. Convert numbers stored as text ("2608 ", "2,608") to numbers. Keep text columns exactly as written (trim whitespace only).
- Ignore the used range reported by the file (the sheet claims A1:XFD81), scan only the real populated cells.
- Payment block (optional import): total sq ft, Rate, Increase Rate, 4 Track Charges, Transport, CGST 9 percent, SGST 9 percent, Final Billing Amount. Cross-check the total with the window rows and warn on mismatch.
- Support Devanagari / Marathi text (UTF-8) in remarks and terms without corruption. Ignore the terms and conditions, signature and notes rows.
- Validate: duplicate SR NO / location, missing width/height, zero or negative values, unrealistic sizes (under 300 mm or over 6000 mm), missing window type.
- Also provide a downloadable blank Excel TEMPLATE (same layout as the sample) from the import screen, plus a short instruction note.
