The appearance setting changes only the sidebar and selected hero panels. Main workspace content stays light in both theme choices. Desktop navigation groups use adjacent flyouts; mobile keeps the inline expandable list.

**Why:** The user clarified that the rest of the page should remain light even when the sidebar and hero panels use the dark palette.

**How to apply:** Keep global workspace surface tokens light, scope theme-specific colors to the sidebar and selected heroes, and preserve the desktop/mobile navigation split.
