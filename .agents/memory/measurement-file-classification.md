---
name: Per-file measurement classification
description: User decisions about classification and reference metadata for retained measurement sheet files.
---

Each retained measurement file/version owns its own type—Quotation measurement or Final measurement—and Reference. Reference choices combine active users with reusable custom names. Custom reference management requires measurement edit permission; deleting a custom option must not erase labels already saved on historical versions.

**Why:** The user explicitly specified that Reference is selected per uploaded file and requested reusable custom names with add, edit, and delete controls.

**How to apply:** When changing measurement upload or version workflows, keep classification and reference metadata version-scoped and preserve historical labels.
