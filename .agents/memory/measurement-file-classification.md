---
name: Per-file measurement classification
description: User decisions about classification and reference metadata for retained measurement sheet files.
---

Each retained measurement file/version owns its own type—Quotation measurement or Final measurement—and Reference. Reference choices combine active users with reusable custom names and customer-name references. Customer-name references are managed separately from Client records. Reference management requires measurement edit permission; deleting an option must not erase labels already saved on historical versions.

**Why:** The user specified per-file Reference selection and reusable add/edit/delete options, then chose a separate customer-name list rather than reusing or modifying the Client catalogue.

**How to apply:** Keep classification and reference metadata version-scoped; keep customer-name references independent of Client records, and preserve saved labels when managed reference options are renamed or deleted.
