---
name: Map-provider cost constraint
description: The user wants site map selection without API billing or paid credentials.
---

Use no-key map and geocoding services for order locations; do not add a billable Google Maps API or require a map API key without asking first. Be clear that no third-party public map provider can be guaranteed free or available forever.

**Why:** The user selected OpenStreetMap after asking that map selection be free for life.

**How to apply:** For future map/location changes, avoid paid API calls and disclose external provider limits, terms, or availability risks instead of promising lifetime service.
